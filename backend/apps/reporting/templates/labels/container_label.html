{# Container label -- one page per physical container. PLACEHOLDER LAYOUT, like the report templates beside it: the production artwork is NASAT QA's to author. Unlike a report this one carries no draft banner, deliberately. A label is 50x25mm and every millimetre is spoken for; a banner would push out the analyse-by date, which is the one field on here that stops a sample being lost. What the layout is built around, in priority order, because a label is read at arm's length in a cold room: 1. The barcode, and the same code in plain text under it. The text is not decoration -- it is what an analyst types when the scan fails, which on a frosted bottle is often. 2. The analyse-by date. This is the field that makes the label worth printing: ISO/IEC 17025:2017 7.4.1 asks the laboratory to protect the item's integrity, and on a container that reduces to "deal with this before the date on the side". 3. Everything else, small.
